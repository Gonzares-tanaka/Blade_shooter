# BLADE / CLOSE QUARTERS 0.9.0

**300秒の1面道中＋巨大戦艦ボス戦**です。5分はボス登場までの時間で、ボス撃破までが1面です。
移動で弾を避け、刃の軌跡だけで残弾を斬り、射撃停止の隙に接近します。装甲・砲台を先に壊すと攻める経路が変わります。
子機版 `../../shooting_1` は変更していません。

## PCで起動

作業ルートから実行します。Python 3.12 / Pyxel 2.9.9で確認しています。

```powershell
.\blade_shooter\run.ps1
.\blade_shooter\run.ps1 --seed 42
.\blade_shooter\run.ps1 --course stage --section 6
.\blade_shooter\run.ps1 --course boss
```

既存の `shooting_1/.venv` を利用できます。新規環境は `blade_shooter/` で `python -m venv .venv`、`.venv\Scripts\python.exe -m pip install -r requirements.txt` を実行してください。
`--section` は1から7。1=0秒、2=40秒、3=80秒、4=120秒、5=160秒、6=210秒、7=300秒のボス登場から開始します。
途中開始は確認用にHP3・過去敵なしで始めます。通常の通しプレイ中はHP回復や敵弾消去はありません。
`--seed` は後半の組み合わせを固定します。引数なしは7で、リトライも同じ出現表です。

## フリック操作と武器比較（0.9.0）

開始前・結果画面のX / GKDのB / Webの武器設定ボタンから武器を選びます。上下で項目、左右で値を変更し、Enter/Z または START/A/B で設定を閉じて開始します。
武器はプレイ中固定、リトライで保持。「54秒・武器比較」/ COMPARE: WEAPONSは毎回同じ出現表、FREEは通常の1面や練習コースです。
直接起動：`run.ps1 --course compare --weapon lance`。
比較区間は0–9秒=小型、9–18秒=装甲、18–27秒=突進、27–36秒=弾幕、36–45秒=2種混成、45–54秒=3種混成。出現条件は全武器共通です。

### フリック判定の調整値

**事前タップ・ダブルタップの判定は廃止。** ブレイドとアックスは横（左右）、ランスは縦（上下）の素早い払いで、指を離す前に一回だけ攻撃します。どちら向きでも前方攻撃です。
普通のドラッグは移動として即座に渡し、速く、武器の軸に近い動きだけを攻撃候補にします。指を置き続けたまま、移動→払い→移動→次の払いが可能です。

全値は `config.py: WEB_TOUCH`。距離は**256×320のゲーム座標px**へ正規化し、CSS拡大率やdevicePixelRatioに依存させません。移動倍率1.2×1.3は判定距離に掛けません。

| 設定 | 値 |
|---|---|
| フリック距離 | 14px以上 |
| 速度 | 0.40px/ms以上（400px/秒） |
| 候補の計測窓 | 最大90ms。接触開始ではなく、速い動きの開始から計測 |
| 方向の許容 | 横または縦の軸から左右それぞれ35°以内（正負どちらも可） |
| 新しい払いへの復帰 | 90msの静止、または120px/秒以下のゆっくりした移動 |
| 静止後の最初の速度標本 | rAFで静止を観測したあと、直近1フレーム（16.67ms）から計測 |
| 不成立の保留移動 | 125px/秒以下で滑らかに戻す。離指・キャンセル時は残りを破棄 |

速い候補の変位は保留し、成立した払いの変位は自機へ渡しません。短すぎる候補の変位は一度に戻さず、上記速度で移動へ戻します。
成立したmoveで即発動し、同じ速いストロークは再使用可能になっても再発動しません。一瞬止めるかゆっくり動かしてから、再使用可能な状態で新しい払いを始めます。
再使用待ち中に始まった払いは攻撃を予約せず消費します。待ちが終わっただけで勝手に攻撃しません。
touchcancel / pointercancel、非表示・blur・pagehide、設定遷移、表示サイズ変更で入力・候補・保留移動を解除。ゲーム画面のスクロール・ダブルタップ拡大も抑止します。

### 武器の調整表

唯一の設定は `config.py: WEAPONS`。再使用間隔は**攻撃入力が受理され、振り始めた瞬間**からゲームの戦闘時間で計ります（停止・ヒットストップ中は進みません）。
`shot_stop`は振り始め＋有効＋戻りの合計から導出し、終了フレームまで新規ショット停止。その後、残る再使用待ちの間は共通ショットが再開します。

| 武器 | 威力 | 最大リーチ | 刃/穂先の幅 | 振り始め | 有効 | 戻り | 再使用 | ショット停止 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| ブレイド | 40 | 60px | 4px・150°薙ぎ | 0.070秒 | 0.100秒 | 0.240秒 | 1.00秒 | 0.410秒 |
| アックス | 80 | 44px | 14px・110°薙ぎ | 0.035秒 | 0.120秒 | 0.500秒 | 1.20秒 | 0.655秒 |
| ランス | 32 | 94px | 16px・正面固定 | 0.055秒 | 0.160秒 | 0.200秒 | 0.82秒 | 0.415秒 |

距離は自機中心の4px前の関節から。ブレイドは内端30〜外端60、アックスは斧頭30〜44が有効です。
ランスは自機を動かさず、長さ28pxの穂先を46→94pxへ伸ばします（有効時間の65%で最大）。柄には攻撃・弾消し判定がありません。
全武器で移動可能・攻撃無敵なし、敵一体につき一振り一回。判定は有効時間に刃が実際に掃く部分だけ。前フレームの残像は消え、戻りに判定はありません。

## 道中と戦艦

| 経過時間 | 主役 | 変化と混成 |
|---|---|---|
| 0:00〜0:40 | 小型編隊 | 正面、左右斜め、左右画面外からの側方進入。途中で装甲を追加 |
| 0:40〜1:20 | バックアタック | 下端予告→停止射撃→上へ離脱。小型と装甲を時差で追加 |
| 1:20〜2:00 | 突進 | 左右・中央から予告方向へ固定突進。編隊と装甲を追加 |
| 2:00〜2:40 | 装甲 | HP32、早い初弾と1.9秒のOPEN。後方敵・小型を時差で追加 |
| 2:40〜3:30 | 弾幕 | 5方向を撃つ装甲、通常装甲、小型の左右交互の配置 |
| 3:30〜5:00 | 混成 | 確認済みの15秒パターンを6回。後方型・突進型を交互に選び、左右も変化 |
| 5:00〜 | 巨大戦艦 | 新規道中出現を停止。4秒の登場＋道中残弾の退場を待ってから射撃 |

後半の混成候補4種類は単独での自動入力15秒攻略を確認しています。
同じ組み合わせの連続を禁止し、第三の敵を各候補の序盤に限定して、次の候補の後方敵と突進が重ならないようにしています。
未撃破の混成90秒では約70秒が2種類、約18秒が3種類。早期撃破で画面の敵を減らす攻略もできます。

| 戦艦部位 | HP | 攻撃と狙い |
|---|---|---|
| 左砲台 L | 180 | 左から中央への5方向扇、3回。中心から左を優先するとこの射線が消える |
| 右砲台 R | 180 | 右から中央への5方向扇、3回。左砲台より1.25秒遅れて撃つ |
| 中央主砲 MAIN | 240 | 点滅・正面線の予告後、密度の高い9方向を3回 |

3部位はいつでも任意の順で狙え、全部のHPが0になると1面クリアです。破壊された部位は新規射撃を止め、発射済みの弾は残ります。
戦艦は8.4秒周期。左・右・中央の初撃を0.90・2.15・3.75秒へずらし、5.0〜8.4秒は全砲台が新規射撃を止めるOPENです。
砲台の外周が点滅して予告し、部位ごとのHPバーと破壊画像を表示します。
船体の接触判定より手前、部位の約52px下から刃が届きます。弾を斬ったあとも側面や自機近くの弾には注意してください。
ショットのみでも破壊できます。自動入力の例はボス単体約103秒、接近斬撃は約29〜38秒です。人の難易度評価とは区別しています。

## 維持した近接戦闘

通常ショット間隔0.14秒、威力1、速度300px/秒は全武器共通。各武器の全動作中は新規ショットを停止し、発射済みの弾は残します。
斬撃は内端30・外端60・幅4px、振り始め0.07・有効0.10・振り終わり0.24秒、威力40、再使用1秒です。
攻撃・弾消しは表示する刃と同じ範囲・同じ時間だけ。斬撃に無敵はありません。
既存のHP3、被弾後1.2秒、後方敵の入場接触猶予0.35秒を維持しています。

## Editorで画像・音楽・SEを編集する

**原本は `assets/blade.pyxres`。52色パレットは同じ場所の同名 `assets/blade.pyxpal` です。**
起動時は読み込むだけで、画像やSound/Musicをコードで再生成しません。
ビルドも原本のバイト列をそのままコピーします。Editorで保存した変更を上書きしません。

作業フォルダから：

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\edit.ps1
```

または `blade_shooter/` から、インストール済みPythonで直接開きます。

```powershell
..\..\shooting_1\.venv\Scripts\python.exe -m pyxel edit assets\blade.pyxres
```

1. Image / Sound / Musicのタブを選んで編集します。
2. Ctrl+Sまたは上部の保存アイコンで保存します。
3. ゲームを再起動して確認します。起動中の自動再読込は行いません。
4. Web/GKDへ反映するには、下記のビルドを実行します。

`.pyxpal` は色番号0〜51を順番どおり52行のRGB16進数で保持します。並べ替え・16色化をしないでください。
Editor 2.9.9は同名の `.pyxpal` を読み、52色の選択欄を表示します。ゲームも同じファイルを読みます。
`config.py` の `PALETTE` と異なる順序のパレットはビルド時に検出します。色番号0はスプライトの透明色です。
パレットの仕様：[Pyxel公式FAQ](https://github.com/kitao/pyxel/blob/main/docs/faq-ja.md)。

| 音声チャンネル | 役割・同時発生時の優先順位（左が高い） |
|---|---|
| 0 | BGMメロディ。SEからは使用しない |
| 1 | BGMベース。SEからは使用しない |
| 2 | 戦艦登場 → 戦艦予告 → 戦艦発射 → 空振り → 弾消し → 後方射撃予告 → 後方発射 → 突進開始 → ショット |

斬撃で複数機を倒した場合は斬撃命中を優先し、撃破数だけSEを重ねません。
SEのためにBGMを停止しません。一時停止・タイトル・結果では意図的にBGMを停止し、再開時は先頭から再生します。

`blade_shooter/` で `python build.py` を実行します。原本の素材はバイト列のまま同梱します。

- `dist/web/`：この中身をGitHub Pagesの公開対象へ置きます。
- `dist/blade-shooter-web.zip`：Web一式。Pyxel 2.9.9を公式CDNから取得するためネット接続が必要です。
- `dist/blade-shooter-gkd.zip`：GKD Pixel 2 / PlumOS用。

ローカルWeb確認：`python -m http.server 8000 --directory dist/web`。
GKD ZIPは展開して `blade-shooter.sh` と `blade-shooter/` を既存Portsへ並べてコピーします。
ランチャーは `/storage/pyxel_Python/bin/python3 -u main.py --gkd` で起動し、SELECTでPortsへ戻ります。
