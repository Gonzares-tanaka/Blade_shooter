# BLADE / CLOSE QUARTERS 0.5.0

256×320、**120秒の1面道中**です。小型編隊・装甲・突進・後方出現の4種類で、接近する相手とタイミングを選びます。
上から回り込む敵は、下端の予告から入場し、射撃後に上へ逃げる敵へ置き換えました。
従来の「敵3種」80秒と「後方出現」80秒の確認コースも残しています。開始画面の左右／Webのコース切替で選べます。
子機、ボス、武器強化、成長、アイテムはありません。子機版 `../../shooting_1` は変更していません。

## PCですぐ遊ぶ

作業フォルダ `C:\temp\mypyxel\shooting_2` から実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\run.ps1
```

専用 `.venv` がなければ既存の子機版の `.venv` を使用します。
新しい環境を作る場合は、このREADMEがある `blade_shooter/` で次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

開発確認はPython 3.12 / Pyxel 2.9.9です。Pyxel Editorも同じ2.9.9を使います。

通常ショットは自動ですが、剣を振る全動作の間は新規発射を止めます。発射済みの味方弾は残ります。
Z/Aの押しっぱなしは連斬になりません。SELECTはタイトル・停止・結果・ヒットストップ中にも有効です。
タッチした位置へワープせず、指の移動量だけを使います。仮想十字キー・攻撃ボタンはありません。
往復ドラッグ、長押し、複数指をダブルタップに数えません。操作設定と誤認防止の値は前版から維持しています。

## 1面の道中（STAGE 1 / APPROACH）120秒

| 区間 | 固定配置 | 遊びと休息 |
|---|---|---|
| 0〜25秒：小型編隊 | 2秒x128 / 8秒x80 / 14秒x176、各3機 | まとめ斬りへ位置合わせ。終わりには次の敵まで間を取る |
| 25〜45秒：装甲 | 25.8秒x96 / 33.8秒x176 | FIRINGを待ち、OPENへ踏み込んで一撃 |
| 45〜65秒：突進 | 46.5秒x64 / 52.5秒x192 / 58.5秒x128 | 単独から順番に、予告を見て迎撃または回避 |
| 65〜85秒：後方出現 | 67秒x128 / 76秒x184 | 下端予告から横へ避け、敵が上へ逃げたあと後ろへ入って斬る |
| 85〜110秒：2種類の組み合わせ | 装甲85.8秒x80＋編隊88.5秒x176、装甲97秒x112＋後方98.2秒x176 | どちらを先に斬るか、OPENへ接近するか後方の射線を離れるか |
| 110〜120秒：最後のまとめ斬り | 編隊110.5秒x104 / 112.2秒x152 | 射撃しない高速通過編隊を斬る見せ場。約118〜120秒は休息 |

出現順・位置・移動パターン・各敵の射撃間隔は固定です。通常の狙い弾と突進の予告開始時の狙いだけは、その時点の自機位置を使います。乱数は使いません。
同時の攻撃をずらし、後方の3発は組み合わせる装甲の最初のOPEN中へ入れています。前方に残った弾は消えません。
生存すれば仮クリアになり、その場でリトライできます。敵を全滅させる必要はありません。
ボスへの接続箇所は `Game.finish_course()`。現在は仮クリアを表示し、`pending_scene="boss"` と完了イベントを渡すところまでです。

### 後方出現敵：横へ避けてから反撃

1. 下端の固定x座標をBELOWのマーカーと予告音で1.2秒表示します。この時点では機体・攻撃判定はありません。
2. 下から56px/秒で入り、y288で停止。入場中と停止直後0.35秒は、この敵本体だけ接触判定を待ちます。リング表示が目印です。敵弾や他の敵への無敵は付きません。
3. 停止後1.4秒、画像点滅・上向きの点線・UP SHOT・予告SEで発射を予告します。
4. 上へ42px/秒の遅い弾を0.55秒間隔で3発撃ちます。画面内で停止している間だけ射撃します。
5. 射撃を終えたら、上へ44px/秒で移動して逃げます。ESCAPE表示中は新しく撃ちません。自機は125px/秒なので、横から後ろへ入って追いかけられます。

HP12で斬撃なら一撃。入場中・離脱中にも通常ショットや斬撃で倒せます。経路は固定で追尾しません。
敵は緑のU字フックと上向きの砲身です。点線とマーカーは予告表示だけで、弾消し・攻撃判定はありません。
既存と同じく刃が通った敵弾は消せますが、後ろや自機のすぐ近くを守る判定は追加していません。

### 区間の先頭から確認する

開始・結果画面の**上下**で開始区間、**左右**でコースを選びます。Webの上部ボタンでも同じ選択ができます。
1は通しプレイ、2〜6はその区間の先頭からHP3で開始し、前の敵や弾は持ち込みません。リトライも選択した区間からです。
区間変更は開発用の確認手段で、プレイ中・一時停止中には切り替えません。

PCで後方区間から直接開く例（作業フォルダから）：

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\run.ps1 --course stage --section 4
```

`main.py` に直接渡す場合も `--course stage --section 4`。コースは `stage` / `classic` / `rear`、区間番号は1始まりです。

後方出現だけを練習する `rear` は80秒。0〜26秒は単独、26〜54秒は装甲との組み合わせ、54〜80秒は編隊との組み合わせです。

## 従来コース：敵3種（THREE ENEMIES）80秒

| 区間 | 出現時刻 | 試すこと |
|---|---|---|
| 0〜16秒：装甲敵 | 2秒、中央に1機 | 赤いFIRINGを見て待ち、青緑のOPEN中に近づいて一撃 |
| 16〜36秒：小型編隊 | 18秒・25秒、各3機 | 紫の逆三角3機へ位置を合わせ、一振りで巻き込む |
| 36〜56秒：突進敵 | 38秒・45秒、各1機 | ピンクの予備動作と固定の点線を見て、引きつけて斬るか横へ避ける |
| 56〜80秒：混成 | 58/62/67/69/72/74秒 | 少数の組み合わせ。弾を斬って穴を作り、移動して抜ける |

区間名とヒントを画面上部へ表示します。次の敵まで数秒の余白があり、敵も弾もいなければBREATHERと表示します。
出現順・時刻は固定です。時間だけで生存クリアし、敵を全滅させる必要はありません。
突進敵は入場後、**予告開始時の自機位置で方向を固定**します。1.2秒予告し、突進中も追尾しません。
小型編隊は同じ相対配置で飛び、一度だけ薄い射撃を行います。装甲敵の周りに密な弾幕は追加していません。

装甲HP32は通常弾32発（連続命中で約4.5秒）、斬撃威力40なら一撃です。
編隊は各HP2、突進敵はHP24。すべて通常ショットでも倒せます。突進は回避だけでも対処できます。

## 近接戦闘の維持値

- 自機16×16、HP3、敵弾に対する判定は中央の白点・半径2px。敵本体には機体の外周で接触します。
- 斬撃は支点から30〜60px、幅4px、左前方から右前方へ150度。
- 振り始め0.07秒・有効0.10秒・振り終わり0.24秒。全区間で新規ショット停止。
- 振り始めと振り終わりには攻撃・弾消し判定がなく、移動は可能です。
- 再使用1.0秒、威力40、命中停止0.05秒。これらは調整済み0.2.0から変更していません。
- 攻撃は実際に刃が通った場所と時間のみ。前フレームの軌跡は次のフレームを保護しません。
- 自機移動と刃の回転、敵弾の移動を短い時間区間で照合し、すり抜けを防ぎます。
- 同じ敵への斬撃ダメージは一振り1回。斬撃による無敵、突進する自機、消せない弾はありません。
- 横・後方・刃の内側の弾、斬ったあとに来る弾には回避が必要です。

| 1 | 空振り・剣を振る音 |
| 2 | 斬撃命中 |
| 3 | 弾消し |
| 4 | 敵撃破（通常ショット） |
| 5 | 自機被弾 |
| 6 | 開始・リトライ |
| 7 | ステージクリア |

| 9 | 突進開始 |
| 10 | 下端の出現予告・停止後の上向き射撃予告 |

| 32 / 33 | BGMのメロディ素材 |
| 34 / 35 | BGMのベース素材 |

**Music 0** が短い仮BGMです。現在はCH0=`33,32,33`、CH1=`34,35`。Editorで順番や音符を編集できます。
MusicのCH2/CH3は空のままにしてください。SE用に予約しています。

| 音声チャンネル | 役割・同時発生時の優先順位（左が高い） |
|---|---|
| 0 | BGMメロディ。SEからは使用しない |
| 1 | BGMベース。SEからは使用しない |
| 2 | 空振り → 弾消し → 後方射撃予告 → 後方発射 → 突進開始 → ショット |
| 3 | ゲームオーバー → クリア → 被弾 → 斬撃命中 → 通常撃破 → 開始 |

同じイベントが複数機・複数弾から来ても各チャンネル最大1回/フレームです。
弾消しは最短0.10秒、斬撃命中は0.06秒、通常撃破は0.08秒の間隔を置きます。高優先のSEは低優先音を中断できます。
斬撃で複数機を倒した場合は斬撃命中を優先し、撃破数だけSEを重ねません。
SEのためにBGMを停止しません。一時停止・タイトル・結果では意図的にBGMを停止し、再開時は先頭から再生します。

## 一か所で調整する

戦闘・出現の調整は **`config.py`** です。変更後はゲームを再起動し、配布版は再ビルドします。

| 対象 | 設定 |
|---|---|
| 敵HP | `ARMOR_HP=32`, `SMALL_HP=2`, `CHARGER_HP=24` |
| 敵弾速度 | `ARMOR_BULLET_SPEED=38`, `SMALL_BULLET_SPEED=48` px/秒 |
| 装甲射撃間隔・発射/停止時間 | `ARMOR_FIRE_INTERVAL=0.55`, `ARMOR_FIRE_SECONDS=1.65`, `ARMOR_REST_SECONDS=2.5` 秒 |
| 小型の射撃時刻 | `SMALL_FIRST_SHOT=2.0` 秒（各機1回） |
| 突進予告・速度 | `CHARGER_WARNING_SECONDS=1.2`, `CHARGER_SPEED=140` px/秒 |
| 編隊配置・パターン | `FORMATION_OFFSETS`, `FORMATION_PATTERNS`。`line`は従来、`parade`は64px/秒・射撃なし |
| 道中の出現・区間名・長さ | `STAGE_PLAN`。各行の `length`、`title`、`hint`、`waves` |
| 従来の単体確認・後方確認 | `CLASSIC_PLAN`, `REAR_TEST_PLAN` |
| 既定コース | `DEFAULT_COURSE="stage"` |
| 後方出現敵HP・半径 | `REAR_HP=12`, `REAR_RADIUS=10` |
| 下端マーカー時間・入場速度 | `REAR_MARKER_SECONDS=1.2`, `REAR_ENTRY_SPEED=56` |
| 入場時の接触猶予 | 入場中＋`REAR_CONTACT_GRACE=0.35` 秒 |
| 停止位置・上への離脱 | `REAR_PATTERNS`（`stop_y=288`, `escape_vx=0`）, `REAR_EXIT_SPEED=44` |
| 後方射撃の予告・速度 | `REAR_WARNING_SECONDS=1.4`, `REAR_BULLET_SPEED=42` |
| 後方射撃の間隔・回数 | `REAR_SHOT_INTERVAL=0.55`, `REAR_SHOTS=3` |
| 斬撃の範囲・時間 | `BLADE_*`（0.2.0から維持） |
| タッチ・実ボタン割当 | `WEB_TOUCH`, `KEYBOARD_INPUTS`, `GKD_INPUTS` |

出現行は `(区間内の秒, 敵種, x座標, 移動パターン)`。敵種は `formation` / `armor` / `charger` / `rear` です。
例えば `(3.5,"formation",176,"line")` は、その区間の開始から3.5秒後にx176へ通常編隊を出します。
`compile_course()` が区間長を足し、区間の開始・出現の絶対時刻・終了時刻をまとめて計算します。
`STAGE_SECONDS` は合計から計算するので手で二重に設定しません。区間を短くした際、出現時刻が外に出るとビルド時にエラーで知らせます。
各敵の射撃時刻は入場・停止からの固定時間で決まります。装甲との組み合わせを変えるときはOPENとの重なりも再確認してください。
