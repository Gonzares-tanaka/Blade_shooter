# 検証記録 — 2026-10-22 / 0.2.0

## 変更と採用値

斬撃中は新しい通常ショットを停止し、発射済みの味方弾はそのまま更新します。
振り終わりの最終フレームまで止め、次フレームから自動射撃へ戻ります。停止分を溜めて連射しません。
操作設定、威力40、敵HP、敵弾速度、敵出現表、HP3、被弾後無敵は変更していません。
斬撃による無敵や消せない弾は追加していません。

調整箇所は `config.py` に集約しています。距離は自機中央の4px前にある腕の支点から測ります。

| 設定 | 0.1.0 | 0.2.0 |
|---|---|---|
| 刃の外端 `BLADE_REACH` | 68px | 60px |
| 刃の内端 `BLADE_INNER` | 12px | 30px |
| 刃の幅 `BLADE_WIDTH` | 4px | 4px（維持） |
| 振り始め `BLADE_WINDUP` | 0.07秒 | 0.07秒（維持） |
| 有効時間 `BLADE_ACTIVE` | 0.12秒 | 0.10秒 |
| 振り終わり `BLADE_RECOVERY` | 0.14秒 | 0.24秒 |
| 再使用 `BLADE_COOLDOWN` | 0.50秒 | 1.00秒 |
| 威力 `BLADE_DAMAGE` | 40 | 40（維持） |

振り始め0.07秒・攻撃0.10秒・振り終わり0.24秒の全区間で新規ショット停止。
攻撃・弾消しは中央の0.10秒だけです。振り終わりも移動でき、0.24秒で約30px移動できます。
命中時の0.05秒のヒットストップ中は、自機・敵・弾を従来どおり停止します。
刃の内端を30pxにしたことで、自機本体に近い弾は攻撃中も消せません。
外端60pxと敵本体の半径15pxがあるため、装甲敵には接触する手前から十分届きます。
腕と刃本体の表示も新しい長さへ合わせています。

## 調整の順序と静止連斬の比較

まずショット停止・軌跡判定だけを変更し、従来の調整値で確認しました。
自機を初期位置に固定し、再使用可能になるたび斬る入力では無傷で60秒生存しました。
振り終わりを0.24秒へ延ばすだけでも無傷でクリアしたため、長い移動不能時間を付けずに
刃の内外端・有効時間・再使用間隔を上記の値へ調整しました。

`tests/check_balance.py` の実測結果です。敵配置・敵弾・HPをそのまま使い、移動入力はありません。

| 比較 | 結果 | 残HP | 斬撃回数 |
|---|---|---|---|
| ショット停止＋軌跡判定のみ、調整値は従来値 | 60.0秒クリア | 3 | 116 |
| 上記＋振り終わり0.24秒のみ | 60.0秒クリア | 3 | 116 |
| 採用値、静止で最速斬撃を反復 | **47.783秒でゲームオーバー** | 0 | 47 |

この結果は今回の固定ステージと入力での確認です。あらゆる位置・タイミングの安全性を網羅したものではありません。
実測JSONは `verification/v0.2.0/balance.json` に保存しています。

## 確認した場面

Python自動テスト32件とNode.jsジェスチャーテスト8件を実行しました。

- 前方の弾列11発を1回の斬撃で7発消去。その穴へ75px前進し、HP3のまま突破。
- 振り終わりに届く前方弾・横弾は消えず、静止すれば被弾。同じ場面で振り終わり中に移動すれば無傷で回避。
- 横からの弾に対して、その場で連斬しても被弾。自機周辺の一括消去なし。
- 刃がすでに通った左前方へ次フレームに追加した弾は消えず、後方・範囲外・内端より近い弾も残る。
- 振り始め・振り終わりでは、刃の表示があっても攻撃・弾消し判定は空。新しい通常弾も出ない。
- 発射済みの味方弾は斬撃中も飛び続け、終わると自動射撃へ戻る。
- 高速回転、自機の移動前後、敵弾がフレームの始点と終点の間だけ刃に交差するケースを確認。
- 装甲敵へ安全な間合いから1回で撃破。同じ敵へのダメージは1斬撃1回。
- 接触・被弾は斬撃中も有効。移動、HP3、被弾後無敵、即リトライ、停止・再開は維持。
- GKD用SELECTの終了処理はタイトル・プレイ・停止・結果・ヒットストップ中すべてで有効。

判定は刃本体の4頂点を入力にし、前フレームからの回転を最大5度、自機移動を最大4pxに細分して接続します。
敵弾自身の移動も同じ時間区間に分けて照合します。判定用ポリゴンをそのまま青白い軌跡として描画し、刃本体も共通の頂点で描きます。
各フレームで判定を破棄して作り直すため、前フレームの軌跡は次のフレームを保護しません。
両断の線・命中火花・弾消去火花などの演出は判定へ参照しません。持続する残像の攻撃領域はありません。
ヒットストップ中は全体を止めて直前の絵を保持し、新たな弾消しは処理しません。
