### Windows WebKitとSafari向け操作層

Windows上のPlaywright WebKitでは、ゲーム全体の起動を確認できませんでした。
Pyodideの `Aborted()` / `Unreachable code should not be executed` が `pyxel.init()` 中に発生しました。
ゲーム・入力を一切含まない64×64の公式ランタイムだけのページでも同じ停止を再現しています。
`verification/webkit/runtime-baseline.json` に、Python入口到達=true / 画面初期化完了=falseとエラーを保存しました。
これはWindows WebKitでの結果であり、iPhone Safari実機で同じ障害が起こると断定していません。

外部WASMだけを置き換えた独立確認では、配布するHTML/CSS/操作JSをWebKitで動かし、
実タッチのダブルタップ、相対ドラッグ、3連タップ・長押し・遠いタップ・遅いタップの除外、
キャンセル・blur時の入力解除、320×568で縦横比0.8・ページのはみ出しなしを確認しました。
`tests/smoke_webkit_controls.cjs` → `WEBKIT_CONTROLS_OK`、JS例外0件。
この操作層の検証を、ゲーム全体のSafari対応確認とは扱っていません。

## 再実行

READMEのPython環境で、`blade_shooter/` をカレントディレクトリにします。

```text
python build.py
python -m unittest discover -s tests -v
node --test tests/test_gestures.cjs
python tests/smoke_desktop.py
python -m http.server 8766 --bind 127.0.0.1 --directory dist
```

別の端末で `node tests/smoke_web.cjs`。開発用のPlaywrightとEdgeが必要です。
WebKitの切り分けには `node tests/smoke_web.cjs --webkit`、
`node tests/smoke_webkit_controls.cjs`、`node tests/check_webkit_runtime.cjs` を使います。
Playwrightや検証ブラウザは配布ZIPへ含めていません。
