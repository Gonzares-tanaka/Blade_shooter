# 検証記録 — 2026-10-25 / 0.5.0

## 実際の道中の長さと内容

1面道中は**ゲーム内120秒**です。一時停止中は進まず、斬撃のヒットストップはこの時間に含みます。
敵4種類の導入から2種類の組み合わせ、最後のまとめ斬りと休息へつなぎ、仮クリア・即リトライまで実装しました。

| 時間 | 内容 | 固定出現 |
|---|---|---|
| 0〜25秒 | 小型編隊のまとめ斬りと位置合わせ | 2 / 8 / 14秒、各3機 |
| 25〜45秒 | 装甲の射撃停止を待って接近 | 25.8 / 33.8秒 |
| 45〜65秒 | 突進の予告を読み、回避か迎撃 | 46.5 / 52.5 / 58.5秒 |
| 65〜85秒 | 後方出現から横へ避け、追い越されたあと反撃 | 下端予告67 / 76秒 |
| 85〜110秒 | 装甲＋編隊、装甲＋後方出現 | 85.8＋88.5秒 / 97＋98.2秒 |
| 110〜120秒 | 射撃しない通過編隊のまとめ斬り、最後に休息 | 110.5 / 112.2秒、約118秒以降は空白 |

小型編隊は計6編隊18機、装甲4機、突進3機、後方出現3機、合計28機です。
初登場は単独の種類で動きを示します。狙い弾と突進の予告開始時の狙いだけは自機位置を使い、出現・経路・攻撃周期に乱数はありません。
混成では小型の射撃を装甲のOPENへ、後方の3発も装甲の最初のOPENへずらしています。前方の残弾は消さず、移動で回避する余地を残しました。

## 後方出現敵の置き換え

以前の「上から側面を通って後ろへ回る」経路はゲームから取り除きました。
新しい敵は緑の上向き砲身の既存スプライトを使い、次の固定動作を行います。

1. 下端の出現x座標をBELOWマーカーとSound 10で1.2秒予告。この間は機体も当たり判定もありません。
2. 下から56px/秒でy288まで入り、停止します。入場中と停止後0.35秒は、その敵本体との接触だけ猶予を与え、リングで示します。
3. 1.4秒の点滅・上向き射線・UP SHOT・Sound 10で発射予告。
4. 画面内で停止したまま、上向き42px/秒の弾を0.55秒間隔で3発。
5. 射撃を終え、上へ44px/秒で離脱。ESCAPE中は射撃しません。自機125px/秒で横から後ろへ入れます。

HP12は維持し、斬撃40で一撃、通常ショットでも撃破できます。追尾・画面外射撃・移動しながらの射撃はありません。
入場の接触猶予は自機全体の無敵ではなく、敵弾と他の敵には通常どおり被弾します。

## 調整と開発用の確認手段

`config.py` の `STAGE_PLAN` に区間長・見出し・ヒント・全出現表を集約しました。
出現行は `(区間内秒, 敵種, x座標, パターン)`。
区間長を変えると `compile_course()` が後続の区間開始・出現・ステージ終了を連動して再計算します。
短くした区間から出現時刻が外へ出る場合はエラーにします。終了時刻を別に手入力する必要はありません。

開始・結果画面の上下、Webの開始区間ボタン、CLIの `--course stage --section 1〜6` から先頭区間を選べます。
前の区間の敵・弾を持ち込まずHP3で開始し、リトライも選択を維持します。プレイ中は切替できません。
従来の装甲・編隊・突進・混成を確認する80秒コースは出現時刻・配置を維持しました。
後方出現敵を単独から確認する80秒コースも用意し、旧・回り込みの動きは残していません。

`Game.finish_course()` を道中終了の境界とし、完了イベントと次の接続先 `pending_scene="boss"` を通知します。
現在は仮クリアのみで、ボスへ自動遷移する実装はありません。

## 維持した戦闘・素材・操作

自機速度125px/秒、斬撃内端30px・外端60px・幅4px、振り始め0.07秒・有効0.10秒・振り終わり0.24秒、再使用1秒、威力40、命中停止0.05秒を維持しました。

斬撃の無敵・自機突進・残像の判定・後方保護はなく、移動可能・同じ敵へ一振り1回です。
通常の小型・装甲・突進のHP・移動・射撃設定も維持しています。最後の小型編隊だけは射撃なし・64px/秒の通過パターンを使います。

画像・BGM・SEの `.pyxres`、52色 `.pyxpal` は0.4.0の原本をバイト単位で保持しました。
新しい下端マーカー・入場リング・予告線だけコード描画です。画像バンク、Sound、Musicは起動・ビルドで再生成しません。
以前Editorで保存した画素色2、Sound 0速度3、Music 0 CH0=`33,32,33` を、実ゲームと配布Webで再確認しました。
Sound 10を出現・射撃予告、11を射撃に使い、BGM CH0/1とSE CH2/3の分離、優先順位と発音間隔を維持しています。
今回EditorのUIで素材を書き換える操作はしていません。

Webのドラッグ＋ダブルタップ／十字キー＋Z、GKDの十字キー＋A／SELECT終了を維持しました。
GKDランチャーは変更せず、`/storage/pyxel_Python/bin/python3 -u main.py --gkd` で起動します。
