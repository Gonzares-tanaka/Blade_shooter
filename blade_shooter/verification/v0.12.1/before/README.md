# BLADE / CLOSE QUARTERS 0.12.0

**300秒の1面道中＋巨大戦艦ボス戦**です。道中300秒で新規出現を止め、最大2秒で残敵・残弾を整理して戦艦を登場させます。撃破表示のあとにリザルトへ進み、リトライまたはタイトルへ戻れます。
移動で弾を避け、刃の軌跡だけで残弾を斬り、射撃停止の隙に接近します。装甲・砲台を先に壊すと攻める経路が変わります。
子機版 `../../shooting_1` は変更していません。

## 第1面の一巡・スコア・CUT（0.12.0）

武器を選び、Webは左移動＋右フリックを使用して出撃。300秒道中→各エリアの変化アイテム→残敵整理→巨大戦艦→3部位破壊→STAGE CLEAR（1.8秒）→リザルト→リトライ／タイトルです。リザルトとゲームオーバーでは矢印上下＋Z/Enter、GKDは上下＋A/STARTで項目を選びます。Webは「もう一度」「タイトルへ戻る」も使用できます。SELECTの終了は全状態で有効です。

`config.py: SCORING` に得点を集約。小型は1機100、突進200、後方250、装甲500、左砲台3000、右砲台3000、中央5000。ショットは基本点、近接は2倍。一振りの2体目以降は1体につき200点を追加します。戦艦全体の撃破ボーナスは固定10000点で、倍率をかけません。部位・戦艦の得点はそれぞれ1回だけ。弾消しは得点にしません。

`config.py: CUT` の猶予は1.5秒。武器の有効範囲で消した弾1発につきCUT +1。同じ弾は消してリストから外すため重複しません。最後の弾消しからの時間切れと被弾で現在CUTを0へ戻し、最大CUTはプレイ終了まで保持します。ポーズ・残敵整理・ボス登場演出・ヒットストップ・リザルトでは猶予を進めません。敵本体を斬ってもCUTは増えません。

上部24pxのHUDは左SCORE、右CUT、下段HP・武器・ステージ・時間。スコア6桁、CUTは4桁分の固定枠で通常は2桁のゼロ表示（CUT 00）。増加時は枠の中心を保って少し拡大します。枠を超えた値は末尾+で示し、実際の得点・CUT記録は丸めません。近接得点は通常より少し大きく、一振りの複数撃破はDOUBLE/TRIPLEを短く表示します。新しい表示より敵弾と自機を後に描き、判別を妨げない順序にしています。

リザルトにはスコア・ベスト・最大CUT・ボス撃破・終了時の武器を表示。リトライではHP・道中時間・敵・弾・アイテム・ボス・スコア・CUTを初期化し、最初の武器選択とWeb操作方式は保持します。1面リトライは途中開始した場合も0秒からです。

## ベストスコアの保存

- Web：同じオリジンの `localStorage`、キー `blade-shooter.best.v1`。JSON `{schema:1,best_score:数値}`。リロード後にも読み込みます。プライベートブラウズやサイトデータ削除では保持されない場合があります。
- PC/GKD：`main.py` と同じアプリフォルダーの `save/best.json`。GKDなら展開した `blade-shooter/save/best.json`。一時ファイルへ書いてから置換します。ZIPには個人のsaveフォルダーを含めません。更新時は既存saveフォルダーを残してください。
- 読込不正・保存拒否・書込失敗は例外を外へ出さず、起動中のベストをメモリで維持します。失敗時もリザルト・リトライを続けられます。

## ステージデータと開発ログ

`stages.py: STAGES` には第1面だけを登録しています。予定数は3ですが、第2/第3面の配置・背景・ボスはありません。ステージ番号、出現表を作るfactoryと道中長、混成候補、背景名、BGM、アイテム出現時刻と位置、ボスfactory、ボスBGM、クリア遷移先を `StageDefinition.build()` でまとめます。第1面の出現表は従来の `config.py: stage_plan()` です。

`progress.py: RunState` が現在ステージ・スコア・HP・現在武器・現在CUT・最大CUT・猶予を保持。`Game.enter_stage(number, carry_run=True)` はこのオブジェクトを保持して敵・弾・ステージ進行だけを作り直せます。将来は登録データに `next_stage` と `clear_target="next_stage"` を指定して遷移でき、現状は `result` へ進みます。

PC/GKDは `run.ps1 --debug` または `main.py --gkd --debug`、Webは `play.html?debug=1`。標準出力／ブラウザコンソールへ `BLADE_DEBUG` から始まるJSONで加点・CUT増加・最大更新・リセット・ステージ終了を出します。通常は無効で、表示には出しません。ゲーム内 `debug_log` も直近256件まで保持します。

## 1面BGMとEditor

今回の仕様に合わせ、Music 0とSound40〜51を通常のEditor用ノート列へ収録しました。テンポ150、3声・各128個の16分音符、32音ずつの4ブロックで約12.8秒ループです。Music 0はメロディ `[40,41,42,43]`、伴奏 `[44,45,46,47]`、ドラム `[48,49,50,51]`。Pyxel Editorの音符・音量・音色・再生順を編集でき、通常起動では書き換えません。

## PCで起動

作業ルートから実行します。Python 3.12 / Pyxel 2.9.9で確認しています。

```powershell
.\blade_shooter\run.ps1
.\blade_shooter\run.ps1 --seed 42
.\blade_shooter\run.ps1 --course stage --section 6
.\blade_shooter\run.ps1 --course boss
```

既存の `shooting_1/.venv` を利用できます。新規環境は `blade_shooter/` で `python -m venv .venv`、`.venv\Scripts\python.exe -m pip install -r requirements.txt` を実行してください。
`--section` は1から7。1=0秒、2=40秒、3=80秒、4=120秒、5=160秒、6=210秒、7=300秒のボス練習から開始します。
途中開始は確認用にHP3・過去敵なしで始めます。通常の通しプレイではエリア終了時のアイテムでHP回復・武器交換ができます。敵撃破では残弾を消しません。
`--seed` は後半の組み合わせを固定します。引数なしは7で、リトライも同じ出現表です。

| バックアタック | 1:20 | 1:20.5〜1:22 |
| 突進 | 2:00 | 2:00.5〜2:02 |

自機から64px以上離れ、敵・残弾から余裕のある候補を優先します。通常は0.5秒待ち、局所的に危険なら最大2秒まで待ちます。最後は残敵整理・ボス登場を待たせません。8秒滞在してゆっくり下へ漂い、その後上方向へ退場します。見送れます。ポーズ・バックグラウンドによる停止・ヒットストップ中は、種類・滞在・通知のタイマーも止まります。

`config.py` の `AREA_ITEM` が唯一の調整表です。`positions` は `(64,200),(192,200),(128,176),(48,248),(208,248)`、`switch_seconds=0.8`、`stay_seconds=8`、`drift_speed=4`、`exit_speed=96`。位置・距離は256×320ゲーム座標px、速度はpx/秒。`settle_seconds`・`max_delay`・安全距離・点滅・通知時間もここで調整します。出現時刻は既存 `stage_plan()` の各 `length` の累積に連動します。途中開始では過去エリアの報酬を出さず、リトライで出現状態を初期化します。敵の乱数と独立した固定シードで種類を選びます。

編集原本は `assets/blade.pyxres`。画像バンク0の `(0,96),(16,96),(32,96),(48,96)` の各16×16pxがハート・剣・斧・槍、SE17が回復・SE18が武器取得です。既存の画素・音・BGM・52色は保持し、起動やビルドで素材を生成しません。

## 左手移動＋右手フリック（0.10.0）

ゲーム表示領域の左側が移動、右側が攻撃。**触れ始めた場所で指の担当が決まり、離すまで固定**します。
左担当が右へ入っても移動のまま。右担当が左へ入っても攻撃のままです。右手を先に置いても動作し、左右各1本を独立して受け付けます。
担当中の側へ置いた余分な指は無視し、空いた担当へ自動で引き継ぎません。担当を取り直すときは一度離して新しく触れてください。

- 左手：速度・方向にかかわらず、移動量だけ自機を動かす相対ドラッグ。触れた座標へワープせず、左手の素早い回避で攻撃しません。
- 右手：剣・斧は左右、槍は上下へ素早くフリック。少し斜めでも可。事前タップ不要、成立したmoveで即発動。払う正負にかかわらず前方へ攻撃。
- 右手は短いブレ・誤方向・遅い動き・再使用待ち中を含め、どの動きも移動には使いません。
- 同じ払いで連続発動しません。一瞬静止するかゆっくり動かしてから次の払いへ。離して触り直しても再入力できます。
- 再使用待ち中に始まった払いは予約せず破棄。待ち終了だけで勝手に攻撃しません。

右側に薄い境界線と「斬撃エリア」を表示します。ガイドはpointer-events:noneで入力を遮らず、敵弾と自機が見える薄さにしています。
自機の位置ではなく接触開始位置で担当を決めるため、自機が右側にいても左手のドラッグで移動できます。

### 調整箇所

全設定は `config.py: WEB_TOUCH`。距離は**256×320のゲーム座標px**へ変換し、CSS倍率・devicePixelRatioに依存しません。移動倍率1.2×1.3はジェスチャー判定へ掛けません。

| 項目 | 初期値 |
|---|---|
| 境界 `move_region_ratio` | 左から50%（x=128）。境界ちょうどは攻撃側 |
| フリック距離 | 14px以上 |
| フリック速度 | 0.40px/ms以上（400px/秒） |
| 計測窓 | 90ms。速い動きの開始から計測 |
| 方向の許容 | 指定の横/縦軸から±35°、正負どちらも可 |
| 次の払いへの再準備 | 90msの静止、または120px/秒以下の動き |
| 静止後の最初の標本 | rAFで静止を観測後、直近1フレーム（16.67ms）から計測 |

従来の失敗フリックの変位を移動へ戻す処理は削除。右手は攻撃専用です。左右の指が互いの判定をリセットすることはありません。
キャンセル・capture喪失・blur・pagehide・バックグラウンド移行・設定や結果画面への遷移・リサイズでは、両担当・余分な指・攻撃候補・未消費の移動と攻撃を解除します。
一方の指を正常に離しただけでは、もう一方の担当を解除しません。ゲーム領域のtouch-action:noneとイベント抑止でスクロール・拡大ジェスチャーとの競合を防ぎます。

### 武器比較

開始前・結果画面のX / GKDのB / Webの武器設定ボタンから武器を選択。上下で項目、左右で値、Enter/ZまたはSTART/A/Bで設定を閉じて開始します。
1面ではエリア終了アイテムで武器変更可能。リトライでは直前の武器を保持。比較コースはアイテムなし。「54秒・武器比較」は固定出現、FREEは通常の1面や練習コース。直接起動は `run.ps1 --course compare --weapon lance`。
比較区間は0–9秒=小型、9–18秒=装甲、18–27秒=突進、27–36秒=弾幕、36–45秒=2種混成、45–54秒=3種混成です。武器性能・ステージ・戦闘バランスは0.9.0から変更していません。

唯一の設定は `config.py: WEAPONS`。再使用間隔は**攻撃入力が受理され、振り始めた瞬間**からゲームの戦闘時間で計ります（停止・ヒットストップ中は進みません）。

未撃破の混成90秒では約70秒が2種類、約18秒が3種類。早期撃破で画面の敵を減らす攻略もできます。

| 戦艦部位 | HP | 攻撃と狙い |
|---|---|---|
| 左砲台 L | 180 | 左から中央への5方向扇、3回。中心から左を優先するとこの射線が消える |
| 右砲台 R | 180 | 右から中央への5方向扇、3回。左砲台より1.25秒遅れて撃つ |

3部位はいつでも任意の順で狙え、全部のHPが0になると1面クリアです。破壊された部位は新規射撃を止め、発射済みの弾は残ります。
戦艦は8.4秒周期。左・右・中央の初撃を0.90・2.15・3.75秒へずらし、5.0〜8.4秒は全砲台が新規射撃を止めるOPENです。
砲台の外周が点滅して予告し、部位ごとのHPバーと破壊画像を表示します。
船体の接触判定より手前、部位の約52px下から刃が届きます。弾を斬ったあとも側面や自機近くの弾には注意してください。
ショットのみでも破壊できます。自動入力の例はボス単体約103秒、接近斬撃は約29〜38秒です。人の難易度評価とは区別しています。

## 維持した近接戦闘

通常ショット間隔0.14秒、威力1、速度300px/秒は全武器共通。各武器の全動作中は新規ショットを停止し、発射済みの弾は残します。
斬撃は内端30・外端60・幅4px、振り始め0.07・有効0.10・振り終わり0.24秒、威力40、再使用1秒です。
攻撃・弾消しは表示する刃と同じ範囲・同じ時間だけ。斬撃に無敵はありません。
既存のHP3、被弾後1.2秒、後方敵の入場接触猶予0.35秒を維持しています。

## Editorで画像・音楽・SEを編集する

**原本は `assets/blade.pyxres`。52色パレットは同じ場所の同名 `assets/blade.pyxpal` です。**
画像・SE・ボスBGMは原本から読み込みます。1面BGMもMusic 0／Sound40〜51のEditor原本から読み込みます。
ビルドも原本のバイト列をそのままコピーします。Editorで保存した変更を上書きしません。

作業フォルダから：

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\edit.ps1
```

### Sound / Musicとチャンネル

| Sound番号 | 用途 |
|---|---|
| 0 | 通常ショット |
| 1 | 空振り・剣を振る音 |
| 2 | 斬撃命中 |
| 3 | 弾消し |
| 4 | 敵撃破（通常ショット） |
| 5 | 自機被弾 |
| 6 | 開始・リトライ |
| 7 | ステージクリア |
| 8 | ゲームオーバー |
| 9 | 突進開始 |
| 10 | 下端の出現予告・停止後の上向き射撃予告 |
| 11 | 後方出現敵の発射 |
| 32 / 33 | BGMのメロディ素材 |
| 34 / 35 | BGMのベース素材 |

**Music 0** は1面BGM（Sound40〜51）、**Music 1** はボスBGM（Sound36〜39）です。既定のresourceモードでは両方ともEditorの編集を優先します。Sound32〜35には旧仮曲も残しています。
MusicのCH3以降はSE用に空のままにしてください。ボスMusic 1のCH2も空にし、道中のドラムを持ち越さない構成にしています。

| 音声チャンネル | 役割・同時発生時の優先順位（左が高い） |
|---|---|
| 0 | 1面MMLメロディ／ボスBGM。SEには使用しない |
| 1 | 1面MML伴奏／ボスBGM。SEには使用しない |
| 2 | 1面MMLドラム。ボス登場時に停止 |
| 3 | 登場・予告・砲撃・空振り・弾消し・後方警告・突進・ショット |
| 4 | ボス撃破・部位破壊・ゲームオーバー・クリア・被弾・取得・命中・撃破・開始 |

同じイベントが複数機・複数弾から来ても各チャンネル最大1回/フレームです。
弾消しは最短0.10秒、斬撃命中は0.06秒、通常撃破は0.08秒の間隔を置きます。高優先のSEは低優先音を中断できます。
斬撃で複数機を倒した場合は斬撃命中を優先し、撃破数だけSEを重ねません。
SEのためにBGMを停止しません。一時停止・タイトル・結果では意図的にBGMを停止し、再開時は先頭から再生します。

## 調整箇所

戦闘・配置は `config.py` に集約しています。

| 対象 | 設定 |
|---|---|
| 道中区間・全出現 | `stage_plan()` / `STAGE_PLAN`、各行 `(区間内秒, 敵種, x, パターン)` |
| 編隊の構成・経路・初弾 | `FORMATION_OFFSETS`, `FORMATION_PATTERNS`, `SMALL_WARNING_SECONDS` |
| 装甲の射撃・初弾 | `ARMOR_PATTERNS`, `ARMOR_WARNING_SECONDS`, `ARMOR_FIRE_SECONDS`, `ARMOR_REST_SECONDS` |
| 後方・突進 | `REAR_*`, `CHARGER_*` |
| 混成の候補・間隔・シード | `MIX_CANDIDATES`, `MIX_SLOT_SECONDS`, `STAGE_SEED`。`--seed`で上書き |
| 船体の登場・接触範囲 | `BOSS_ENTRY_SECONDS`, `BOSS_Y`, `BOSS_HULL_RECT` |
| 部位HP・位置・弾速・予告・射撃間隔 | `BOSS_PARTS`の`hp`, `x`, `dy`, `radius`, `speed`, `warning_at`, `warning`, `volleys`, `angles` |
| 全砲台の周期と休止 | `BOSS_CYCLE_SECONDS`, `BOSS_OPEN_FROM` |
| 操作・速度 | `KEYBOARD_INPUTS`, `GKD_INPUTS`, `WEB_TOUCH`, `PLAYER_SPEED_PRESETS` |

`stage_course(seed)` が出現表を確定し、`Game`の再開・リトライで同じ表を使います。5:00以降は出現させません。
別コースは `stage`、`compare`（54秒）、`tempo`、`tempo_fast`、`boss`、`legacy`（旧120秒）、`classic`、`rear` の順です。

## Web紹介ページとスマホプレイ

公開先：<https://gonzares-tanaka.github.io/Blade_shooter/>

`index.html` はゲーム紹介ページです。「ブラウザで遊ぶ」でページ内のゲームを起動できます。
`play.html` はゲーム専用画面で、スマホでは広く画面を使えます。
スマホは左手のドラッグで相対移動。右手は剣・斧の横フリック、槍の縦フリックで近接攻撃。事前タップは不要です。読み込み後にゲーム画面をタップし、「開始」を押してください。
音声の有効化には画面タップが必要です。対応ブラウザでは「画面拡大」でフルスクリーンにできます。

紹介ページには実際のゲーム画像、操作説明のスマホ／キーボード切替、1面の流れ、3部位の戦艦紹介、FAQを用意しました。
ゲーム本体のダウンロードは「遊ぶ」を押したときに開始します。通信エラー時はゲーム専用画面内に再読み込みボタンを表示します。
ローカル確認は `python -m http.server 8000 --directory dist/web`。HTML単体だけでなく、生成されたフォルダー一式を使ってください。

`.github/workflows/pages.yml` が `main` へのWeb関連変更のpushでビルドし、`blade_shooter/dist/web/` の中身をGitHub Pagesのルートへ公開します。
GitHub Pagesの公開元はGitHub Actionsです。ソース変更は `web/`、生成・配布用は `dist/web/` と使い分けます。

## 配布物を更新・公開する

`blade_shooter/` で `python build.py` を実行します。原本の素材はバイト列のまま同梱します。

- `dist/web/`：この中身をGitHub Pagesの公開対象へ置きます。
- `dist/blade-shooter-web.zip`：Web一式。Pyxel 2.9.9を公式CDNから取得するためネット接続が必要です。

ローカルWeb確認：`python -m http.server 8000 --directory dist/web`。
