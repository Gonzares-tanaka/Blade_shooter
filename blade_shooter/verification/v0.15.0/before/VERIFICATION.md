# 0.14.1 第2面ボス・交互射撃と全休止（2026-11-13）

## 原因と変更範囲

前版は各機が0.78秒ずつずれた移動位相で個別に発射し、6機生存時は12秒に114回の射撃、定常周期の最大発射間隔は0.36秒でした。機体ごとに低速区間があっても、他機の射撃と残弾が重なっていました。`verification/v0.14.1/timing-comparison.json`に出現表から計算した値を記録しました。

今回は射撃時計だけを共通化。岩の全配置と180秒の道中、3武器の全性能、6機・各HP90、追従0.78秒、12秒の移動航跡（約16〜238px/秒）、弾速126／150／174px/秒は維持しました。無敵化・弾の一括削除・HP変更で隙を作っていません。

## 射撃順と設定

`stage2_config.py: STEALTH_ATTACK`に集約。時刻は登場演出終了後の戦闘時計で、ポーズ・ヒットストップ中は停止します。

| 時刻 | 発射と予告 |
|---|---|
| 0.00〜0.70秒 | 先頭1〜3番だけ発光・照準。全機発射なし |
| 0.70〜2.00秒 | 先頭側だけ射撃 |
| 2.00〜7.00秒 | 全機5秒休止 |
| 7.00〜7.70秒 | 後尾4〜6番だけ発光・照準。全機発射なし |
| 7.70〜9.00秒 | 後尾側だけ射撃 |
| 9.00〜14.00秒 | 全機5秒休止。次の周期へ |

機体間時差0.20秒、各機は初弾から0／0.32／0.64秒に発射。3機生存時は3方向扇弾×3機＋翼2方向×3機＋航跡3方向×3機＝24発を1.04秒に集中させます。最終弾1.74秒から次の初弾7.70秒まで5.96秒。グループが全滅しても枠は飛ばさず、最後の1機も同じ周期です。

扇角は±14度→±20度、翼の角度は±8度→±11度、航跡弾は1方向→±12度を含む3方向へ。予告時の位置を狙って照準を固定し、発射後は直進します。射撃予告は黄の発光、移動予告は薄い矢印に分離。全休止表示と、休止開始0.65秒以降の低速機体のCUT表示を追加しました。CUTは安全保証や弾消去ではなく、低速の攻撃機会の目印です。

発射済み弾は休止・発射元の破壊でも残り、画面外まで自然に流れます。最後の機体を破壊した後のクリア処理による残弾整理は従来どおりです。

固定60Hzの実ゲーム判定と、実Pyxel描画・音声で同じ入力を確認しました。自動入力は移動・斬撃以外の優遇を使わず、HP補充、無敵化、敵への直接ダメージ、弾削除を行いません。描画確認は1描画6更新の加速再生です。人によるプレイとは区別します。

| ブレイド | 60秒・無被弾・CUT 0 | 22.77秒 | 6 | 3 | 3 |
| アックス | 60秒・無被弾・CUT 0 | 22.58秒 | 4 | 2 | 3 |
| ランス | 60秒・無被弾・CUT 0 | 28.87秒 | 10 | 7 | 3 |

コース時間は3秒の登場と1.8秒のクリア表示を含みます。斬撃なしの条件でも自動ショットは通常どおり発射。3条件とも敵弾が自機から50px以内に入るフレームが542あり、最接近は約13.74pxでした。全体では最大24発が画面内に残ります。近接入力では全武器とも残弾3〜6発がある休止中の命中を記録し、その後も無被弾でした。離脱の数は命中から0.25〜1.3秒の間にy275以降まで戻った回数で、単に近接入力した回数ではありません。
