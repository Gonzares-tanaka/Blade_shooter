# BLADE / CLOSE QUARTERS 0.6.0

256×320、標準起動は**30秒の混成テスト / 速度1.3倍**です。
左右／Webのコース切替で、同じ出現表の1.5倍版と比較できます。
装甲＋小型を軸に、後方敵・側方の突進を交互に重ね、射撃の合間に接近して斬ります。
旧120秒と80秒の出現表は比較用に残し、敵の挙動・速度は新設定を共有します。

## PCですぐ遊ぶ

作業フォルダ `C:\temp\mypyxel\shooting_2` から実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\run.ps1
```

専用 `.venv` がなければ既存の子機版の `.venv` を使用します。
新しい環境を作る場合は、このREADMEがある `blade_shooter/` で次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

開発確認はPython 3.12 / Pyxel 2.9.9です。Pyxel Editorも同じ2.9.9を使います。

## 操作

| 操作 | PC / Webキーボード | Web / iPhoneタッチ | GKD Pixel 2 |
|---|---|---|---|
| 移動 | 十字キー | ドラッグした移動量に応じた相対移動 | 十字キー |
| 斬撃 | Z | ダブルタップ | A |
| 開始・リトライ | Enter / Z | 上部の開始・もう一度 | START / A |
| コース切替（開始・結果画面） | 左右キー | コース切替ボタン | 十字キー左右 |
| 開始区間の選択（開始・結果画面） | 上下キー | 開始区間ボタン | 十字キー上下 |
| 一時停止・再開 | P（再開はEnterも可） | 上部の一時停止・再開 | START |
| 終了 | Esc | タブを閉じる | SELECTで即終了してPortsへ |

通常ショットは自動ですが、剣を振る全動作の間は新規発射を止めます。発射済みの味方弾は残ります。
Z/Aの押しっぱなしは連斬になりません。SELECTはタイトル・停止・結果・ヒットストップ中にも有効です。
タッチした位置へワープせず、指の移動量だけを使います。仮想十字キー・攻撃ボタンはありません。
往復ドラッグ、長押し、複数指をダブルタップに数えません。操作設定と誤認防止の値は前版から維持しています。

## 30秒テストへ直接入る

引数なしで30秒コースを選択済みです。Enter / Z、GKDのSTART / Aで開始します。
左右で `tempo`（1.3倍）→ `tempo_fast`（1.5倍）→ `stage`（旧120秒）→ `classic` → `rear` を切り替えます。
Webはコースボタンで同じ順に切り替えます。速度はHUDにも表示します。
上下／開始区間ボタンで0・10・20秒から開始でき、HP3で開始し、リトライも選択を保持します。

```powershell
.\run.ps1 --course tempo
.\run.ps1 --course tempo_fast
.\run.ps1 --course tempo --section 3
```

| 時間 | 組み合わせ | 選択・攻める隙 |
|---|---|---|
| 0〜10秒 | x104→168の装甲＋左右の小型、x152の後方敵 | 小型を先に落とすか、装甲のOPENへ接近。後方の上向き射線は横へ外す |
| 10〜20秒 | x80→176の装甲＋小型、右端→左端の突進 | 固定された予告線から回避するか、斬撃で迎撃する |
| 20〜30秒 | x128→72の装甲＋小型、x192→104の後方敵 | 撃破後の残弾を避ける／斬り、次の装甲へ踏み込む |

未撃破の出現表観測では、2種類が16.02秒、3種類が13.07秒、4種類は0秒です。
3種類の連続は最長3.82秒。最初の入場約0.92秒以降は2種類以上を重ねます。
早期撃破で敵を減らす攻略は許します。狙い弾・固定上向き弾のピークをずらし、回避経路を残します。

装甲は全身が画面内へ入って0.55秒の照準予告後、位置取り中にも初弾を撃ちます。
0.65秒射撃（3方向×2回）→1.9秒のOPEN→次の0.55秒予告。照準は予告開始時の位置へ固定します。
小型はHP2で先手撃破が可能。残した小型は0.35秒の予告後に1回撃ち、そのまま通過します。
突進は0.75秒予告で進路を固定。追尾しません。
後方敵は下端マーカー0.65秒→入場→停止予告0.6秒→上へ2発→射撃を止めて上へ離脱します。
画面外からは撃ちません。

通常ショットは斬撃の全動作中に停止し、発射済みの味方弾・敵弾は残ります。
刃の内端30・外端60・幅4px、振り始め0.07・有効0.10・振り終わり0.24秒、再使用1秒、威力40を維持しています。
斬撃による無敵はなく、弾消しは実際の刃の掃引と同じ範囲・時間だけです。
既存の被弾後1.2秒の猶予、後方敵の入場接触猶予0.35秒も維持しています。

旧120秒は出現表の比較用です。新しい密度はまだ全120秒へ展開していません。
`TEMPO_PLAN` の10秒ブロックを `compile_course()` で連結でき、確認できた構成から道中へ展開できます。
旧道中の出口 `pending_scene="boss"` は維持し、ボス本体は未実装です。

## Editorで画像・音楽・SEを編集する

**原本は `assets/blade.pyxres`。52色パレットは同じ場所の同名 `assets/blade.pyxpal` です。**
起動時は読み込むだけで、画像やSound/Musicをコードで再生成しません。
ビルドも原本のバイト列をそのままコピーします。Editorで保存した変更を上書きしません。

作業フォルダから：

```powershell
powershell -ExecutionPolicy Bypass -File .\blade_shooter\edit.ps1
```

または `blade_shooter/` から、インストール済みPythonで直接開きます。

```powershell
..\..\shooting_1\.venv\Scripts\python.exe -m pyxel edit assets\blade.pyxres
```

1. Image / Sound / Musicのタブを選んで編集します。
2. Ctrl+Sまたは上部の保存アイコンで保存します。
3. ゲームを再起動して確認します。起動中の自動再読込は行いません。
4. Web/GKDへ反映するには、下記のビルドを実行します。

`.pyxpal` は色番号0〜51を順番どおり52行のRGB16進数で保持します。並べ替え・16色化をしないでください。
Editor 2.9.9は同名の `.pyxpal` を読み、52色の選択欄を表示します。ゲームも同じファイルを読みます。
`config.py` の `PALETTE` と異なる順序のパレットはビルド時に検出します。色番号0はスプライトの透明色です。
パレットの仕様：[Pyxel公式FAQ](https://github.com/kitao/pyxel/blob/main/docs/faq-ja.md)。

### Sound / Musicとチャンネル

| Sound番号 | 用途 |
|---|---|
| 0 | 通常ショット |
| 1 | 空振り・剣を振る音 |
| 2 | 斬撃命中 |
| 3 | 弾消し |
| 4 | 敵撃破（通常ショット） |
| 5 | 自機被弾 |
| 6 | 開始・リトライ |
| 7 | ステージクリア |
| 8 | ゲームオーバー |
| 9 | 突進開始 |
| 10 | 下端の出現予告・停止後の上向き射撃予告 |
| 11 | 後方出現敵の発射 |
| 32 / 33 | BGMのメロディ素材 |
| 34 / 35 | BGMのベース素材 |

**Music 0** が短い仮BGMです。現在はCH0=`33,32,33`、CH1=`34,35`。Editorで順番や音符を編集できます。
MusicのCH2/CH3は空のままにしてください。SE用に予約しています。

| 音声チャンネル | 役割・同時発生時の優先順位（左が高い） |
|---|---|
| 0 | BGMメロディ。SEからは使用しない |
| 1 | BGMベース。SEからは使用しない |
| 2 | 空振り → 弾消し → 後方射撃予告 → 後方発射 → 突進開始 → ショット |
| 3 | ゲームオーバー → クリア → 被弾 → 斬撃命中 → 通常撃破 → 開始 |

同じイベントが複数機・複数弾から来ても各チャンネル最大1回/フレームです。
弾消しは最短0.10秒、斬撃命中は0.06秒、通常撃破は0.08秒の間隔を置きます。高優先のSEは低優先音を中断できます。
斬撃で複数機を倒した場合は斬撃命中を優先し、撃破数だけSEを重ねません。
SEのためにBGMを停止しません。一時停止・タイトル・結果では意図的にBGMを停止し、再開時は先頭から再生します。

## 一か所で調整する

戦闘・出現の調整は `config.py` に集約しています。変更後は再起動し、配布物をビルドします。

| 対象 | 設定・現在値 |
|---|---|
| 自機 | 基準 `PLAYER_SPEED=125` × `PLAYER_SPEED_PRESETS`（1.3 / 1.5）＝162.5 / 187.5px/秒。タッチ相対移動も同倍率。加減速なし |
| HP | 小型2 / 装甲32 / 突進18 / 後方12。突進だけ24から減少 |
| 装甲 | 入場150 / 離脱180px/秒、停止y132、寿命6.4秒、予告0.55・射撃0.65・OPEN1.9秒、間隔0.45秒 |
| 敵弾 | 装甲100 / 小型110 / 後方92px/秒 |
| 小型 | 移動72px/秒、初弾1.75秒・予告0.35秒。`FORMATION_PATTERNS` でパターンを選択 |
| 突進 | 入場170 / 突進225px/秒、停止y100、予告0.75秒 |
| 後方 | マーカー0.65秒、入場120 / 離脱96px/秒、停止y288、予告0.6秒、0.38秒間隔で2発 |
| 混成出現 | `TEMPO_PLAN`。3個の10秒ブロック。標準 `DEFAULT_COURSE="tempo"` |
| 旧出現表 | `STAGE_PLAN`, `CLASSIC_PLAN`, `REAR_TEST_PLAN` |
| 斬撃・入力 | `BLADE_*`, `WEB_TOUCH`, `KEYBOARD_INPUTS`, `GKD_INPUTS` |

出現行は `(区間内秒, 敵種, x座標, 移動パターン)`。
`compile_course()` が区間長から開始・出現・終了時刻を連動計算し、区間外の出現を拒否します。
同じ出現表を両速度で共有し、プレイ中は切り替えません。

## 編集後のビルドとWeb

`blade_shooter/` で実行します。ビルド自体はPython標準ライブラリのみです。

```powershell
..\..\shooting_1\.venv\Scripts\python.exe build.py
```

生成物：`dist/web/`、`dist/blade-shooter-web.zip`、`dist/blade-shooter-gkd.zip`。
`.pyxres` と `.pyxpal` はWebのpyxapp内とGKD ZIP内へ同じバイト列で収録します。
`tools/create_placeholder_resource.py` は初期作成用で、起動・ビルドから呼びません。既存原本があれば書き込まず終了します。
`tools/add_rear_resource.py` は0.4.0の追加専用で、通常は実行しません。追加領域かSound 10/11に内容があれば上書きせず終了します。
0.6.0でも画像・Sound・Music・52色パレットをそのまま流用し、原本のバイト列も変更していません。

```powershell
python -m http.server 8000 --directory dist/web
```

PCは `http://localhost:8000/`。iPhoneは同一LANのPCのIPとポートで開きます。
最初にPyxel画面をタップして音声を有効にし、上部の開始を押します。CDNランタイムのためインターネット接続が必要です。
GitHub Pagesには `dist/web/` の中身全部を公開用 `docs/` 等へコピーします。リポジトリ配下でも動く相対URLです。
公開先リポジトリは未指定なので、今回GitHubへ公開する操作はしていません。

既存の動作済みランチャー方式は変更していません。
