# 検証記録 — 2026-10-24 / 0.3.0

## 実装と維持した仕様

80秒の固定テストステージに変更し、装甲敵・小型編隊・突進敵と、最後の少数混成を実装しました。
0〜16秒は装甲、16〜36秒は編隊、36〜56秒は突進、56〜80秒は混成です。
次の出現まで数秒の空白があり、区間名と判断のヒントを常時表示します。

斬撃の内端30px・外端60px・幅4px、有効0.10秒、振り始め0.07秒、振り終わり0.24秒、
再使用1.0秒、威力40、命中停止0.05秒は0.2.0の値を維持しています。
斬撃中の新規ショット停止、発射済み弾の維持、実際の刃の掃引だけの攻撃・弾消し、
一振りで同じ敵へ1回、斬撃無敵なし、移動可能、操作設定を維持しています。
突進の高速移動でも敵本体と通常ショットがすり抜けないよう、相対移動の区間を照合しています。

敵HP・弾速・射撃間隔/停止時間・突進予告/速度・編隊配置・出現表は `config.py` に集約しました。
新しい主な値は突進HP24、予告1.2秒、突進140px/秒、編隊の相対配置 `(-22,0),(0,-6),(22,0)` です。
装甲HP32、編隊各HP2、装甲弾速38、小型弾速48、装甲射撃間隔0.55秒/発射1.65秒/停止2.5秒は既存値を使用します。
ボス・成長・強化・アイテム・新種の消せない弾は追加していません。
